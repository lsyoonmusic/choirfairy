# Choir Fairy (합창요정) — by ASIMORPH's Fellas

실시간 기음($f_0$) 추적 **최대 96 dB/oct 서지컬 로우컷** + **20배음 스펙트럼 피크 추출 스테레오 합창 더블러** + **배음 상단 타이밍 오프셋 원본 에어 블렌더** VST3입니다.

---

## Sine Fairy에서 진화한 핵심 설계

1. **피치 급변 시 "꿀렁꿀렁" 제거 — 듀얼 모드 YIN + 핑퐁 뱅크 크로스페이드 (`PitchTrackerYIN.h`, `ChoirDoubler.h`)**
   - 포물선 보간 부호 버그를 수정하고 최신 샘플 기준 역방향 윈도우로 지연 시간을 절반 가까이 줄여 **±0.5센트 이내**로 $f_0$를 추적합니다.
   - `±0.78 반음` 이내의 비브라토·인토네이션은 부드럽게 따라가고, 그 이상의 **멜로디 음정 도약**은 2홉 확인 후 즉시 스냅하며 **Bank A ↔ Bank B(22 ms 동전력 크로스페이드)**로 전환해 음 사이를 훑고 지나가는 꿀렁임이 사라집니다.
2. **20배음 피크 추적 & 언코릴레이티드 스테레오 사인 뱅크 (`HarmonicAnalyzer20.h`, `ChoirDoubler.h`)**
   - 좁은 직교 락인 복조 대신 **2048-pt Hann FFT 로컬 스펙트럼 피크 탐색 + 주변 골짜기 노이즈 플로어 차감**으로 `H1..H20` 레벨 엔벨로프를 울렁임 없이 추적합니다.
   - 좌/우 독립 20배음 사인 뱅크에 디튠(`±Detune`), 좌/우 비대칭 하스 마이크로 딜레이(`0.72x / 1.18x Timing ms`), 독립 휴먼 드리프트, 황금비 비상관 초기 위상을 적용해 모노 호환성을 지키면서 풍성한 스테레오 합창감을 만듭니다.
3. **20배음 상단 원본 에어 타이밍 오프셋 블렌드 (`ChoirDoubler.h`)**
   - 동적 LR4 하이패스($(N+0.5)f_0$) 위쪽의 숨소리·자음·에어감은 원본 신호를 그대로 뽑아 더블러와 맞물린 좌/우 비대칭 코러스 마이크로 딜레이(`AIR BLEND`)로 섞어줍니다.
4. **최대 96 dB/oct 서지컬 피치 트래킹 로우컷 (`TrackingLowCut.h`)**
   - 최대 8단 직렬 Cytomic TPT SVF(16차 Butterworth)로 **`OFF / 12 / 24 / 36 / 48 / 72 / 96 dB/oct`** 기울기를 지원합니다.
