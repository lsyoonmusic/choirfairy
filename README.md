# Choir Fairy v2 (HQ Lookahead Edition) — by ASIMORPH's Fellas

DAW 자동 레이턴시 보정(PDC, `4096` 샘플 = `85.3 ms @ 48 kHz`)을 활용해 실시간 제약을 풀고, **4096-pt 8배 중첩 WOLA 선형 위상 프로세싱**과 **논코잘(Non-Causal) 룩어헤드 20배음 SMS 합창 재합성**으로 정밀도를 극대화한 스튜디오용 스테레오 더블러 + 서지컬 로우컷 VST3입니다.

---

## v2 (HQ Lookahead) 핵심 업그레이드

1. **4096-pt 8x 중첩 WOLA & 4홉(42.7 ms) 프리 룩어헤드 (`ChoirFairyV2Engine.h`)**
   - `44.1/48 kHz`에서 `4096` 샘플(`11.7 Hz/bin`), `88.2/96 kHz`에서 `8192` 샘플(`11.7 Hz/bin`)로 전 샘플레이트에서 동일한 초고해상도 스펙트럼과 `~85.3 ms` PDC 레이턴시를 유지합니다.
   - 스테레오 복소 패킹 FFT/IFFT와 4096-pt 선형 보간 사인 LUT를 적용해 풀 4보이스 선형 위상 모드에서도 가벼운 CPU 부하를 유지합니다.
2. **±0.1센트급 하이브리드 기음 추적 + 5프레임 룩어헤드 글리치 제거 (`SpectralFrameAnalyzer.h`)**
   - 윈도우 정중앙 대칭 YIN + 4096-pt FFT 배음 에너지 스코어링 + 다중 배음(`H1..H6`) 로그-포물선 가중 보간으로 음정 오차를 `±0.1~0.5센트` 수준까지 줄였습니다.
   - 재생 시점 기준 미래 프레임까지 함께 참조하는 논코잘 연속성 필터로 단발성 옥타브 튐을 지연 없이 제거하며, 각 배음 $k=1 \dots 20$의 실제 피크 주파수 $f_k$와 노이즈 플로어 차감 진폭 $A_k$를 정밀 추출합니다.
3. **McAulay-Quatieri 제로 워블 합창 재합성 (`2-VOICE` / `4-VOICE`) (`SmsChoirSynth.h`)**
   - 음정이 유지되거나 비브라토가 걸릴 때는 매 홉의 시작/끝 프레임 사이를 샘플 단위로 부드럽게 선형 보간합니다.
   - 음정이 급변(`> 0.75 반음`)하면 룩어헤드로 도약 시점을 미리 파악해 이전 음 배음은 그대로 페이드아웃(**Partial Death**), 새 음 배음은 정확한 새 피치에서 페이드인(**Partial Birth**)하여 꿀렁거림이 원천 차단됩니다.
4. **선형 위상(Linear Phase) / 최소 위상(Min Phase) 서지컬 로우컷 (`OFF ~ 96 dB/oct + BRICKWALL`)**
   - 선형 위상 모드에서는 위상 왜곡 0으로 기음 바로 아래를 최대 `BRICKWALL`까지 잘라내며, 타격감이 중요한 소스를 위한 `MIN PHASE` 전환 스위치도 제공합니다.
   - `> (N + 0.5) * f0` 상단 원본 에어 대역 역시 선형 위상으로 분리해 2/4보이스 비대칭 코러스 마이크로 딜레이(`AIR BLEND`)로 섞어줍니다.
